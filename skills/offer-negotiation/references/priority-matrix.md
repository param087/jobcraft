# Offer priority matrix

| Component | Typical negotiability | Notes |
|---|---|---|
| Base salary | Medium | Bands are often fixed; movement within band is common. |
| Sign-on bonus | High | Easiest lever for one-time gaps or forfeited bonuses. |
| Equity / RSUs | Medium | Ask for grant value, vesting schedule, refresh policy. |
| Annual bonus target | Low | Usually tied to level. |
| Title / level | Medium | Affects band; worth asking if evidence supports it. |
| Start date | High | Rarely contested. |
| PTO | Low–Medium | Policy-driven; extra days sometimes possible. |
| Remote / location | Medium | Depends on policy. |
| Learning budget, relocation | Medium–High | Often discretionary. |

## Script skeleton

1. Thank them; restate enthusiasm for the role.
2. Name the one primary gap with a specific number and a brief reason
   (scope, comparable offer the user actually has, forfeited compensation).
3. Name one secondary ask.
4. Ask what is possible; stay collaborative ("Is there flexibility on…").
5. Confirm the timeline for a response.

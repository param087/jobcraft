# Cover letter template

Dear [Hiring Manager name, or "Hiring Team" if unknown],

**Paragraph 1 — Opening (2–3 sentences)**
Name the role. One specific reason this company or problem fits the user's
trajectory, drawn from the job description or user-supplied facts only.

**Paragraph 2 — Evidence (4–6 sentences)**
Two achievements from the resume that map directly to the job's top
requirements. Use the user's real numbers. Mirror the employer's wording where
truthful.

**Paragraph 3 — Close (2–3 sentences)**
What the user would prioritize early in the role. Ask for a conversation.
Thank them.

Sincerely,
[Name]
[Email] · [Phone] · [Link]

---

Formatting rules: no headers or tables, plain paragraphs, 220–300 words
unless told otherwise, no exclamation marks, no "I am writing to apply".

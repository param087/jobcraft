# Bullet rewriting formula

`[Action verb] + [what you did] + [how / with what] + [measurable result]`

Rules:

- Start with a strong past-tense verb (Led, Built, Reduced, Shipped,
  Negotiated). Avoid "Responsible for", "Helped with", "Worked on".
- One idea per bullet, 1–2 lines maximum.
- Keep the user's original numbers. If a bullet has no number and the user
  has not given one, write `[add metric: e.g. % faster, $ saved, users]`
  as a visible placeholder rather than inventing a figure.
- Mirror the job description's terms when the underlying work matches.
- Order bullets within a role by relevance to the target job, not
  chronology.

Example transformation:

- Before: "Responsible for the data pipeline and helped the team with
  reporting."
- After: "Built an Airflow data pipeline feeding weekly finance reports,
  cutting manual preparation from 2 days to `[add metric]`."
